# Historias — Persona externa (técnico, sin cuenta)

- **HU-0401** Como técnico externo, quiero abrir la solicitud por QR o enlace sin iniciar sesión, para reportar el servicio en sitio. → [[programacion]]
  - [ ] La URL lleva el slug de la sede; no necesita subdominio ni sesión.
- **HU-0402** Como técnico externo, quiero reportar equipo, acción, materiales, horario y fotos, para dejar evidencia del trabajo.
  - [ ] Las fotos se reducen en el navegador y se suben una a una.
- **HU-0403** Como técnico externo, quiero firmar "actividad realizada por", para validar el reporte.
  - [ ] La firma es obligatoria.
- **HU-0404** Como técnico externo, quiero descargar el RA-F-33 lleno, para tener mi copia.
  - [ ] Tras enviar, el QR queda cerrado: no se puede diligenciar otra vez.
