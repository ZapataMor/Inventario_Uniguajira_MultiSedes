# Historias — Administrador de sede

- **HU-0201** Como administrador, quiero gestionar el catálogo de bienes (con imagen y carga por Excel), para registrar qué tiene la sede. → [[bienes]]
  - [ ] No puedo eliminar un bien con cantidad > 0.
- **HU-0202** Como administrador, quiero organizar grupos e inventarios con responsable y estado, para saber dónde está cada cosa. → [[inventarios]]
  - [ ] Solo puedo eliminar grupos/inventarios vacíos.
- **HU-0203** Como administrador, quiero agregar bienes por cantidad o por serial a un inventario (uno a uno o por Excel), para llevar existencias reales. → [[inventarios]]
- **HU-0204** Como administrador, quiero mover bienes y seriales entre inventarios, para reflejar traslados. → [[inventarios]]
- **HU-0205** Como administrador, quiero dar de baja bienes con motivo, para conservar evidencia de lo retirado. → [[dados-de-baja]]
- **HU-0206** Como administrador, quiero registrar mantenimientos por serial o en lote, para tener la hoja de vida de los equipos. → [[mantenimientos]]
- **HU-0207** Como administrador, quiero crear solicitudes RA-F-33 con QR y descargar el formato firmado, para documentar servicios externos. → [[programacion]]
- **HU-0208** Como administrador, quiero generar reportes PDF/Excel en carpetas, para entregar informes. → [[reportes]]
- **HU-0209** Como administrador, quiero crear, editar y eliminar usuarios de mi sede, para controlar accesos. → [[usuarios]]
  - [ ] No puedo cambiar mi propio rol ni eliminarme.
- **HU-0210** Como administrador, quiero consultar, exportar y limpiar el historial, para auditar cambios. → [[historial]]
- **HU-0211** Como administrador, quiero gestionar tareas en el inicio, para organizar el trabajo. → [[inicio-y-tareas]]
